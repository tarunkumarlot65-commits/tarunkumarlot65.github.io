# 🌍 GlobeTalk - Chat with the World

A video chat app connecting random users worldwide with real-time translation in 18 languages.

## ✨ Features

✅ Video Chat - Connect with random strangers worldwide  
✅ Real-Time Translation - 18 languages instantly translated  
✅ Age Verification - 18+ users only  
✅ Email OTP - Secure login  
✅ 100% Free - No ads, no cost  
✅ Made in India 🇮🇳  

## 🚀 Quick Start

### Deploy to GitHub Pages (2 mins)

```bash
# 1. Fork this repo or clone it
git clone https://github.com/tarunkumarlot65/globetalk.git
cd globetalk

# 2. Push to your GitHub
git add .
git commit -m "Initial commit"
git push -u origin main

# 3. Enable GitHub Pages
# Settings → Pages → main branch → Save

# Live at: https://yourusername.github.io/globetalk
```

### Run Locally

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server

# Open: http://localhost:8000
```

## 📱 Browser Support

✅ Chrome ✅ Firefox ✅ Safari ✅ Edge

## 🌐 Supported Languages

English, Hindi, Spanish, French, German, Portuguese, Russian, Arabic, Chinese, Japanese, Korean, Vietnamese + more

## 🔒 Security

- Age 18+ verified locally (not stored)
- Email OTP required for login
- WebRTC = direct peer-to-peer (no server sees video/audio)
- No conversation storage
- No ads or trackers

## 📋 Requirements

- Camera & Microphone
- Modern Browser
- Internet Connection
- 18+ years old

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JS
- WebRTC (peer-to-peer video)
- MyMemory API (translation)
- ResponsiveVoice (TTS)
- Backend: Node.js + MongoDB
